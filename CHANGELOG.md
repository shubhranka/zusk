# Changelog

All notable changes to Zusk are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [Semantic Versioning](https://semver.org).

## [0.1.0]

The first public release.

### Added

- Explorer for connections, schemas, tables, views, materialized views and functions, with row estimates and a filter.
- One-click table previews, and a jump box (<kbd>⌘</kbd><kbd>K</kbd>) for tables, views and saved queries.
- SQL editor with PostgreSQL highlighting, autocompletion, and psql-style multi-statement scripts.
- Results grid with typed columns, up to 100,000 rows per run, row filtering, keyboard navigation and copy as text or JSON.
- Structure tab with columns, types, keys, defaults and comments.
- Read-only sessions by default, enforced by the server, with a switch to allow writes.
- Query cancellation, and errors that show the SQLSTATE code, detail, hint and position.
- Saved connections with passwords in the OS keychain, and five TLS modes.
- Saved queries, accent colours, row density and zebra rows.
